A deterministic Python 3.13 standard-library program for the [Worst AI Advice: The 48-Hour Tight Line Open](https://make.fun/bounty/u-steady-ibis-48-6610-worst-ai-advice-the-48-hour-9d91c580) bounty. It writes one UTF-8 line to `/output/entry.txt` (or `MAKEFUN_OUTPUT_DIR/entry.txt` locally), within the 140-character gate.

## Run it

```sh
python3 -P -s main.py
```

The harness provides `/output`; for a local run use `MAKEFUN_OUTPUT_DIR=/some/writable/directory`.

## Test

```sh
python3 -m unittest discover -s tests
```
